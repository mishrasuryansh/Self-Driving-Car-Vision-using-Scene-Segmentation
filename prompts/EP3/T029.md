Add a configurable precision flag; when enabled and CUDA is available, cast model and input tensors to FP16 for inference; when CUDA is unavailable, log a warning and silently use FP32 (not an error — this is an expected, documented fallback, distinct from the "no silent fallback" rule which applies to failure states, not this explicitly-designed device fallback); include a NaN/Inf check on FP16 output with a typed exception if detected.
ENGINEERING STANDARDS
No unguarded precision casting — always check CUDA availability first. No silent NaN propagation.
CONSTRAINTS
