+T044 was built and verified against image jobs, which only ever have terminal states ("completed"/"failed") set synchronously. +TASK OBJECTIVE
+Ensure GET /api/v1/jobs/{jobId} correctly reflects worker-driven status transitions for video jobs, reusing the existing T044 handler without duplicating logic.
+INPUT CONTEXT
+Current files: jobs.py (T044, T053). Reference: Section 8.2 (job status values "queued"|"processing"|"completed", plus the documented "failed" state).
